# Faranux ERP Releases

Public distribution repository for Faranux ERP desktop installers and auto-update files.

- Download the latest Windows installer from the [Releases page](https://github.com/faranux-electronics/faranux-erp-app/releases).
- Application source code is maintained in [inventory-desktop-app](https://github.com/faranux-electronics/inventory-desktop-app).

Release files are published automatically by the source repository's GitHub Actions workflow.
